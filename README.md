# Codex Cloud 작업 공간

Codex Cloud에서 새 프로젝트를 시작하기 위한 저장소입니다.

## 시작하기

1. Codex Cloud에서 이 저장소를 연결하고 새 작업을 시작합니다.
2. 만들고 싶은 기능과 사용할 기술을 작업 요청에 설명합니다.
3. 프로젝트 구성이 정해지면 필요한 의존성, 실행 방법, 검증 명령을 이 문서에 추가합니다.

현재 별도의 의존성 설치나 개발 서버 실행은 필요하지 않습니다.
각 클라우드 작업의 기존 체크아웃을 사용하며, 별도 Git worktree는 요청한 경우에만 만듭니다.

인증 정보는 Codex 환경 설정에서 관리합니다. 비밀 값이나 로컬 환경 파일은 저장소에 커밋하지 않습니다.
